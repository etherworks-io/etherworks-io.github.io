The field is the tool.

The Replicator is a boundary-control machine. Acoustic and electromagnetic fields on the chamber walls scan an object, assemble one, and take one apart. This page is the engineering surface. The company story lives at etherworks.io.

What is actually built

The load-bearing artifact is RSW-1, a native macOS field compiler in twin/. Swift 6 + SwiftUI + Metal. swift build with Command Line Tools. No Xcode.

One architectural law: the emulator API is the hardware API. Frames go to a GPU wave emulator today and to electronics later. Same .fcode. No rewrite.

What is not built yet

  • T0.5 BEM and T1f CBS solver tiers
  • T3 consolidation (melt / wet / latch / occupancy)
  • Drive amplitudes in SI — no quotable levitation or stiffness number until this lands
  • Hardware backend (serial to an RP2350)
  • A complete inverse-scattering reconstruction (L0 is a reflectivity image, not a mesh)
  • Dissolve as coherent perfect absorption — conjugating the drive is not time-reversing the problem
  • Optical compute/memory cavities. Research plan, not the product

The machine (RH-1)

A free-standing column. Two chambers, three plate assemblies, six optically-addressed holographic panels.

  • Build chamber above, storage chamber below. The middle plate is double-faced.
  • Sound is the muscle (24 acoustic channels: 6 panels × 4 PMN-PT drivers). Microwave is the ears and the axial drive. Light is the fingertip.
  • Feedstock rides a bore through the plate axis. Same bore is the optical sightline.
  • Runs in ordinary air. Off-the-shelf parts: single-crystal piezos, FR4-gold PCBs, GaN amplifiers, FPGA control. Novelty is the arrangement, not a new material.

Numbers live in the RH-1 spec. If a page and a paper disagree, the paper wins — and if two papers disagree, that is a bug. Several dimensions currently disagree. Fix them in the spec, then the sites.

How to run the twin

git clone https://github.com/Osika-Innovation/replicator
cd replicator/twin
swift build -c release
./.build/release/fieldc test              # unit suite
./.build/release/fieldc gate --receipt    # physics gates, writes Receipts/
./.build/release/fieldc machine           # RH-1 preset
./.build/release/fieldc gpu               # Metal vs CPU

Gates write receipts. Claims quote receipts. A number without a receipt is not a number we publish.

Claim register

Every public claim is one of three things:

  • Measured — demonstrated in a published experiment, or in a gated run of this twin
  • Derived — follows from measured physics by calculation anyone can check
  • Open — not demonstrated. Named. Kept off the product sentence. Attached to a gate that would settle it

Scan, assemble, and dissolve are the three modes of the design. The acoustic forward model, radiation-force layer, and a partial scan pipeline are gated software today. Subsystem hardware is being prototyped in parallel. There is no integrated v0 in a lab yet.

What we are not saying

The replicator is not a transporter. An object's working description is a chord list (megabytes). Its atomic microstate is not. We are not shipping holographic optical RAM, not claiming the first machine builds the second, and not treating a gated simulation as a measured machine.
