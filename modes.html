Three modes

Same walls. Same fields. Three verbs. Honest order: look first — that is the first real product. Build and unbuild ride the same physics, with more still open.

Look

Ask the object questions. Save its song.

Build

Play the song into empty space until the grains become the object.

Unbuild

Play it the other way so the object becomes grains again.

Look (scan)

Simple

The walls tap and listen. What comes back is a fingerprint of the object — enough to recognize it and, later, to rebuild it.

Technical

Holographic tomography from the boundary. Pipeline in twin: FDTD pulse-echo → S(f) → matrix pencil → chords → .pattern. Scanner-first staging: milliwatt look is the honest first instrument. Twin: wired, partly validated — not yet a trustworthy end-to-end “any object → faithful pattern” product.

Build (assemble)

Simple

Play the fingerprint into the empty room. Sound holds each grain. Heat sticks them. The machine keeps listening while it builds — when the song matches, it is done.

Technical

Inverse solvers (IBP / GS-PAT / Diff-PAT) turn target geometry into boundary drive. T2 Gor’kov for traps; T3 consolidation (melt/latch) not built yet. Call-and-response: chords are drive and acceptance. Drive amplitudes not yet SI — no quotable levitation force.

Unbuild (dissolve)

Simple

Run the song backwards so the thing lets go and becomes powder again. This is the hardest trick. We name it because the design has a place for it.

Technical

Time-reversal / coherent perfect absorption class. In software, dissolve conjugates drive; energy-flow reversal is the real test. Open on finished parts. Most discovery remaining of the three modes.

Why this matters for “machine builds machine”

Look lets a Replicator copy a part it has seen. Build places the atoms of the next machine’s pieces. Unbuild returns scrap to stock. Together they are a factory whose product can be another factory.
