Parts of the machine

Eight pieces. Each one earns its place only if it helps put the right atoms in the right places — including the atoms of the next Replicator.

Build chamber Store Plates Panels Bore Glass Brain (twin) Pattern

1. Build chamber

Simple

The glass room where the object appears. Empty when you start. Full of the thing you asked for when you finish.

Technical

Working volume between the middle and top plates. Compiler preset ~Ø280×300 mm. Field-filled; no in-volume mechanisms.

2. Store (pantry)

Simple

A second room under the floor that keeps the ingredients. Boring powders and grains, ready for the next build. Sorting happens here so the upper room stays for making.

Technical

Mirrored storage chamber below. Same physics class as build: acoustophoretic sort, tomography check, stage. Doctrine: few “boring staples” + trace rack — dense, safe, pattern-free feedstock.

3. Plates

Simple

Flat round lids that face into the rooms. They sing sound and whisper with light. Three lids run two rooms: top, a double-sided middle, and a bottom deck.

Technical

Three dual-carrier plate assemblies. Focusing holograms form a confined column. Spiral EM slots + phononic face. Exact layer counts live in RH-1 spec / CAD — freeze conflicts there.

4. Side panels

Simple

The walls around the back of the glass. They help push from the sides so you are not only squeezing from above and below.

Technical

Six phononic / optically addressed panels → 24 acoustic channels (6×4 PMN-PT) in the current twin preset. They complete solid-angle command. Fancy “terapixel” roadmap language is demoted until measured.

5. Bore (the elevator)

Simple

A narrow hole through the middle of the plates. Material rides up from the pantry. Light can also look along the same tunnel.

Technical

Axial transport + optical stem. Induction / acoustic tube conveying. Bore winding is inert in twin v1 (no transmutation product claims).

6. Glass shell

Simple

The clear wall you can open to put things in. When it is open, the machine only whispers (safe listening). When it is closed, work can be loud inside and quiet outside.

Technical

Low-iron glass enclosure; rotating front half in current design. Door interlock gates drive to mW-class listen when open. “No moving parts” means nothing inside the volume — the enclosure may open.

7. Brain (the twin)

Simple

A computer program that is a pretend Replicator. It practices on the computer before the real walls exist. Same buttons later drive real electronics.

Technical

RSW-1 field compiler (twin/): Swift + Metal. Emulator API = hardware API. See Stack.

8. Pattern (the recipe)

Simple

The file that means “this object.” Not only a drawing — the notes the walls should play.

Technical

.pattern chord list with measured/inferred provenance. Build acceptance listens for the same chords.
