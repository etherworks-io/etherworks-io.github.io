API law

Emulator API = hardware API. MachineBackend: calibrate / play / listen. Emulated today; Serial to RP2350 later.

fieldc / FieldCompilerApp │ FieldUI · FieldGPU · FieldCore │ MachineBackend ─┬─ Emulated (T0/T1/T2) └─ Serial RP2350 (not built)

Scan pipeline

FDTD pulse-echo → S[rx][tx] → matrix pencil → .pattern → Machine View L0. G11/G15 gated. DORT refuses imaging without measured Green’s function.

Formats

  • Chord — pole + port-vector (~100 B)
  • .pattern — scan/object; provenance measured|inferred
  • .fcode — drive schedule; IO unfinished
  • Receipt JSON — gate evidence

Hardware RH-1 (summary)

Two chambers · three plates · six panels (24 acoustic ch) · bore · glass shell. Phonons = force, photons = address/sense. BOM: piezos, FR4-gold, GaN, FPGA. See Parts.
